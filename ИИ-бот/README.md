# ИИ-бот для барбершопа (Telegram)

Бот общается как живой администратор, только на барберские темы, и по просьбе клиента оставляет заявку администратору. Заявки и история диалогов хранятся в SQLite.

## Запуск
1. `pip install -r requirements.txt`
2. `cp .env.example .env` и заполнить: `TELEGRAM_BOT_TOKEN` (@BotFather), `AI_API_KEY`, `ADMIN_IDS`.
3. Заполнить `shop.json` (название, адрес, цены, график) - бот не выдумывает факты, а берёт их оттуда.
4. `python -m bot.main`

## ИИ
Работает с любым OpenAI-совместимым API. По умолчанию - OpenRouter с бесплатными моделями (`:free`, в т.ч. DeepSeek); если основная модель недоступна, пробуются запасные из `AI_FALLBACK_MODELS`. Примеры Groq и Gemini - в `.env.example`.

## Команды
- `/start` - начать диалог заново; `/myid` - узнать свой ID
- Для админов: `/requests` - новые заявки, `/done <номер>` - закрыть заявку. Новые заявки приходят админам сразу.

## Как устроена заявка
Когда клиент подтвердил данные (имя, телефон, услуга, время), модель добавляет в конец ответа служебную строку `[[BOOKING {...}]]`. Бот вырезает её, проверяет поля, сохраняет в таблицу `requests` и уведомляет админов.

Тесты: `pytest`
